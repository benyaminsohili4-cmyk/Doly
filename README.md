# USD & Gold Dashboard

داشبورد فارسی قیمت دلار و طلا با GitHub Actions + GitHub Pages.

## ویژگی‌ها
- دریافت خودکار داده از مخزن `itsyebekhe/usd`
- نگهداری تاریخچه در `data/history.json`
- تحلیل روند بر اساس داده‌های ذخیره‌شده
- نمودار ساده بدون کتابخانه خارجی
- اجرای خودکار هر ۳۰ دقیقه + اجرای دستی
- اگر API موقتاً خراب باشد، آخرین داده معتبر حفظ می‌شود
- خروجی کاملاً استاتیک و مناسب GitHub Pages

## راه‌اندازی
1. این پروژه را داخل یک Repository در GitHub قرار دهید.
2. فایل‌ها را Commit و Push کنید.
3. در Settings → Pages، گزینه Source را روی **GitHub Actions** بگذارید.
4. از Actions → Update Dashboard → Run workflow یک بار دستی اجرا کنید.
5. بعد از موفقیت، GitHub Pages آدرس سایت را نشان می‌دهد.

> نکته: ساختار پاسخ API ممکن است در آینده تغییر کند. اسکریپت چندین ساختار رایج JSON را به‌صورت مقاوم جست‌وجو می‌کند و در صورت نبود داده، سایت را از کار نمی‌اندازد.
